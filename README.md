# 달바람 연대기 — 열두 조각의 달

[게임 플레이](https://chunghyun1995.github.io/moonwind-rpg/)

독자적인 동양 판타지 세계관의 2D 픽셀 액션 RPG 확장판. 12개 외부 지역, 12개 원정 미궁(총 72층), 108개 이야기 목표, 36개 주민 의뢰, 30층 시련의 탑을 제공합니다. 전체 콘텐츠를 즐기는 10시간 이상의 여정을 목표로 설계했으며 실제 완주 시간은 플레이 방식에 따라 달라집니다. 콘텐츠와 시간 예산, 검증 범위는 [CONTENT.md](CONTENT.md)에 기록했습니다.

## 실행과 검사

Node.js에서 `npm start` 또는 `node serve.mjs` 실행 후 http://127.0.0.1:4173 접속. `npm test` 또는 `node tests/smoke.cjs`로 검증합니다. 외부 패키지 설치는 필요 없습니다. `dist/index.html`을 직접 열 수도 있습니다.

GitHub Pages: main / (root). 루트 index.html이 dist/로 이동합니다.

## 조작

- WASD / 방향키 이동, Space 검 공격
- Q 달빛베기, R 회피 돌진
- E 주민 대화 / 조사 / 수집
- 1 회복약, 2 기력약
- J 의뢰 수첩, M 세계 지도, I 장비 가방
- 모바일 화면의 이동·행동 버튼

상점에서 무기·방어구·장신구와 보급품을 구매하고 공방에서 강화·제작하세요. 안내자의 의뢰를 받고 미니맵의 금색 표식을 따라가세요. 문지기 월백에게 원정을 신청할 수 있습니다. 붉은 원은 적의 공격 예고입니다.

localStorage 자동 저장과 저장 파일 내보내기/불러오기를 제공합니다. V1 저장은 유지하고 소지금·물약을 계승합니다. 원정·시련의 완료 층은 저장하지만 해당 층 안의 전투는 새로고침 시 재시작합니다. 멀티플레이나 기기 간 자동 동기화는 지원하지 않습니다.

모든 지도와 그래픽은 코드로 직접 만들었으며 기존 게임의 자산을 사용하지 않았습니다.
